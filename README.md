# Bushido Quest

VR escape game built with Unreal Engine 4, centered around interaction-based progression and reward-driven level design.

## Overview

Bushido Quest is a VR game project developed with Unreal Engine 4.

The experience is structured as a progression-based escape game: the player advances by interacting with the environment, completing challenges, and unlocking new areas or mechanics through rewards.

## Gameplay

The progression is based on a sequence of interactions and unlocks.

Examples of rewards and progression elements include:
- bronze key
- silver key
- gold key
- katana
- climbing
- zipline traversal

Each completed objective unlocks a new part of the experience.

## Tech

- Unreal Engine 4

- gameplay scripting
- progression and reward logic
